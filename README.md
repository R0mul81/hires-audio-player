[ENGLISH]

Thank you for downloading RE:PLAY!
RE:PLAY is a lightweight, high-precision desktop audio player built for
music lovers and audiophiles.

KEY FEATURES:
- Lossless & Hi-Res Playback: FLAC, WAV, ALAC, OGG, MP3, and CUE sheets.
- Bit-Perfect Output: WASAPI Exclusive mode (direct DAC bypass) & Shared mode.
- Real-Time Spectrum Analyzer: 48-band logarithmic FFT audio visualizer.
- AutoEq / Equalizer APO Support: Direct import of .txt headphone profiles.
- 10-Band Graphic Equalizer: Genre presets + custom user presets.
- Synced Karaoke Lyrics: LRC support, auto-fetch via LRCLIB & timestamp tool.
- Built-in Tag & Cover Art Editor: Single and batch metadata editing.
- 20 Custom Skins (including Windows 11 iOS Glassmorphism) & 14 Languages.

SYSTEM REQUIREMENTS:
- Windows 10 or Windows 11 (64-bit)

HOW TO INSTALL:
1. Run "RE_PLAY_Setup.exe".
2. NOTE ON WINDOWS SMARTSCREEN: Because RE:PLAY is a new independent app,
   Windows Defender SmartScreen may show a blue warning window ("Windows
   protected your PC"). Click "More info" -> "Run anyway" to proceed.
3. Follow the installation wizard and launch RE:PLAY from your Desktop.
